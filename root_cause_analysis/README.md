# 根因分析演示系统

## 项目简介

本项目是一个**演示系统**，用于验证基于大语言模型（LLM）和业务本体的根因分析可行性。系统通过LLM理解业务本体并推导因果图，结合DoWhy因果分析框架进行因果推断，最终生成智能分析报告。

## 核心功能（演示验证）

### 1. 业务本体展示
- 查看预定义的制造领域业务本体
- 可视化展示本体的实体和关系
- 了解系统的知识结构

### 2. LLM驱动的因果分析
- 从本体Schema中推断因果关系
- 基于场景描述推导因果图
- 验证LLM的因果推理能力

### 3. DoWhy因果分析
- 量化各因素对结果的影响程度
- 验证因果分析的严谨性
- 生成基础的分析结果

### 4. 智能解释
- 利用LLM生成自然语言分析报告
- 验证AI对分析结果的解释能力

### 5. Web界面演示
- 清晰的分析步骤和工作流
- 交互式用户体验
- 数据可视化展示

## 技术栈

- Python 3.11+
- FastAPI（REST API）
- Streamlit（Web应用）
- OpenAI API / SiliconFlow API（LLM服务）
- DoWhy（因果分析框架）
- NetworkX（图结构处理）
- Matplotlib/Plotly（可视化）
- Pandas（数据处理）

## 快速开始

### 1. 环境准备

#### 前提条件
- Python 3.11 或更高版本
- pip 包管理器

#### 克隆仓库
```bash
git clone <repository-url>
cd root_cause_analysis
```

### 2. 安装依赖

#### 创建虚拟环境（推荐）
```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
# macOS / Linux
source venv/bin/activate
# Windows
venv\Scripts\activate
```

#### 安装依赖包
```bash
pip install -r requirements.txt
```

### 3. 配置

#### API密钥配置
在 `web/modelkey.cfg` 文件中配置LLM API密钥：

```
API Key: your_api_key_here
Base URL: https://api.siliconflow.cn/v1
Model: Qwen/Qwen2.5-7B-Instruct
```

### 4. 启动演示

#### 步骤1：启动本体API服务
```bash
# 在根目录执行
source venv/bin/activate && python web/ontology_api.py
```

#### 步骤2：启动Streamlit Web应用
```bash
# 在根目录执行
source venv/bin/activate && streamlit run web/app.py
```

#### 访问应用
打开浏览器，访问：
- Web应用：`http://localhost:8501`（或其他端口）
- 本体API：`http://localhost:8000`

## 演示流程

### 1. 查看本体关系
- 进入「Agent智能分析」页面
- 点击「查看本体关系」按钮
- 查看本体的实体和关系定义

### 2. 输入场景描述
- 在「步骤1：输入场景描述」中填写简单的问题场景
- 例如："某制造企业生产效率下降，需要分析原因。"

### 3. 选择结果实体
- 在「步骤2：选择结果实体」中选择要分析的目标
- 例如："生产效率"

### 4. 推导因果图
- 点击「推导因果图」按钮
- 查看LLM推导的因果关系

### 5. 根因分析
- 点击「根因分析」按钮
- 查看DoWhy的因果分析结果

### 6. 智能解释
- 点击「生成大模型解释」按钮
- 查看LLM生成的分析报告

## 演示目的

- **验证可行性**：验证通过LLM理解本体并推导因果图的可行性
- **验证分析能力**：验证DoWhy因果分析框架的分析能力
- **验证解释能力**：验证LLM对分析结果的解释能力
- **演示工作流**：演示完整的根因分析工作流

## 注意事项

1. **API密钥**：需要在 `web/modelkey.cfg` 中配置有效的LLM API密钥
2. **服务依赖**：本体API服务必须在Web应用之前启动
3. **网络连接**：需要网络连接以访问LLM API
4. **演示性质**：本系统为演示验证系统，功能和性能均为基础级别

## 故障排除

### 常见问题

#### 1. 本体关系图显示为长方形框框
- 原因：Matplotlib缺少中文字体
- 解决方案：系统已内置字体配置，一般无需手动设置

#### 2. 读取本体Schema失败
- 原因：本体API服务未启动
- 解决方案：确保本体API服务在 `http://localhost:8000` 正常运行

#### 3. 生成大模型解释失败
- 原因：API密钥无效或网络连接问题
- 解决方案：检查API密钥配置和网络连接
