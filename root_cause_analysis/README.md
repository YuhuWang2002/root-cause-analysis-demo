# 制造企业根因分析系统

## 项目简介

本项目是一个基于Agent的智能根因分析系统，专为制造企业设计，用于分析生产效率下降等问题的根本原因。系统通过大语言模型（LLM）理解业务本体并推导因果图，结合DoWhy因果分析框架进行严谨的因果推断，最终生成智能分析报告。

## 核心功能

### 1. 业务本体管理
- 定义制造领域的核心实体（工厂、供应商、员工、产品）及其属性和关系
- 提供本体Schema的REST API接口
- 支持本体关系的可视化展示

### 2. LLM驱动的因果分析
- 从本体Schema中推断因果关系
- 基于场景描述和结果实体推导因果图
- 智能生成分析建议

### 3. DoWhy因果分析
- 量化各因素对结果的影响程度
- 提供严谨的因果推断结果
- 生成指标对比和因果效应分析

### 4. 智能解释
- 利用LLM生成自然语言分析报告
- 提供根因分析和改进建议
- 支持报告下载

### 5. Web界面
- 清晰的分析步骤和工作流
- 交互式用户体验
- 数据可视化和图表展示

## 技术栈

## 安装和部署

### 1. 环境准备

#### 前提条件
- Python 3.11 或更高版本
- pip 包管理器
- Git（用于克隆代码）

#### 克隆仓库
```bash
git clone <repository-url>
cd root_cause_analysis
```

### 2. 安装依赖

#### 创建虚拟环境（推荐）
```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
# macOS / Linux
source venv/bin/activate
# Windows
venv\Scripts\activate
```

#### 安装依赖包
```bash
pip install -r requirements.txt
```

### 3. 配置

#### API密钥配置
在 `web/modelkey.cfg` 文件中配置LLM API密钥：

```
API Key: your_api_key_here
Base URL: https://api.siliconflow.cn/v1
Model: Qwen/Qwen2.5-7B-Instruct
```

### 4. 启动系统

#### 步骤1：启动本体API服务
```bash
# 在根目录执行
source venv/bin/activate && python web/ontology_api.py

# 或使用 uvicorn（推荐）
cd web
uvicorn ontology_api:app --host 0.0.0.0 --port 8000 --reload
```

#### 步骤2：启动Streamlit Web应用
```bash
# 在根目录执行
source venv/bin/activate && streamlit run web/app.py
```

#### 访问应用
打开浏览器，访问：
- Web应用：`http://localhost:8501`（或其他端口，取决于Streamlit的输出）
- 本体API：`http://localhost:8000`

## 操作流程

### 1. 查看本体关系
- 进入「Agent智能分析」页面
- 点击「查看本体关系」按钮
- 系统会读取本体Schema并显示关系图
- 查看本体的实体类型和关系类型详细信息

### 2. 输入场景描述
- 在「步骤1：输入场景描述」中填写问题场景
- 例如："某制造企业在2024年12月发现生产效率相比11月显著下降，需要分析原因并提出改进措施。"

### 3. 选择结果实体
- 在「步骤2：选择结果实体」中选择要分析的目标
- 例如："生产效率"

### 4. 推导因果图
- 点击「推导因果图」按钮
- LLM会基于场景描述和本体Schema推导因果关系
- 查看推导结果，包括因果图结构、推理过程和建议数据字段

### 5. 根因分析
- 点击「根因分析」按钮
- 系统会生成数据并运行DoWhy分析
- 查看指标对比和因果效应分析结果

### 6. 智能解释
- 点击「生成大模型解释」按钮
- LLM会基于DoWhy分析结果生成智能分析报告
- 查看报告并可选择下载

## 注意事项

1. **API密钥**：需要在 `web/modelkey.cfg` 中配置有效的LLM API密钥
2. **服务依赖**：本体API服务必须在Web应用之前启动
3. **资源需求**：LLM推理可能需要较高的计算资源
4. **网络连接**：需要网络连接以访问LLM API
5. **数据安全**：API密钥等敏感信息请勿提交到版本控制系统

## 故障排除

### 常见问题

#### 1. 本体关系图显示为长方形框框
- 原因：Matplotlib缺少中文字体
- 解决方案：确保系统安装了中文字体，或修改代码中的字体设置

#### 2. 读取本体Schema失败
- 原因：本体API服务未启动或端口错误
- 解决方案：确保本体API服务在 `http://localhost:8000` 正常运行

#### 3. 生成大模型解释失败
- 原因：API密钥无效或网络连接问题
- 解决方案：检查API密钥配置和网络连接

#### 4. 页面内容消失
- 原因：会话状态管理问题
- 解决方案：系统已修复此问题，确保使用最新版本
