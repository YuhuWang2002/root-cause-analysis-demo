# 实际场景中构造反事实数据的实用指南

## 📋 问题背景

在真实业务中，我们面临一个根本性的挑战：
- **我们只能观察到一种情况**（实际发生了什么）
- **我们想知道另一种情况**（如果...会怎样？）

这就是因果推断中的**反事实问题**。

## 🎯 五种实用方法

### 方法1：因果模型预测法 ⭐⭐⭐⭐⭐（最推荐）

#### 适用场景
- 有历史数据
- 可以建立因果模型
- 需要量化干预效果

#### 实施步骤

```python
# 步骤1：收集历史数据
historical_data = pd.read_csv('inventory_history.csv')

# 步骤2：建立因果模型
from dowhy import CausalModel

causal_graph = """
digraph {
    product_a_sales -> component_a_consumption;
    product_b_sales -> component_a_consumption;
    product_b_uses_component_a -> component_a_consumption;
    component_a_consumption -> component_a_inventory;
}
"""

model = CausalModel(
    data=historical_data,
    treatment='product_b_uses_component_a',
    outcome='component_a_inventory',
    graph=causal_graph
)

# 步骤3：识别因果效应
identified_estimand = model.identify_effect()

# 步骤4：估计因果效应
estimate = model.estimate_effect(
    identified_estimand,
    method_name="backdoor.linear_regression"
)

# 步骤5：预测反事实结果
counterfactual_data = historical_data.copy()
counterfactual_data['product_b_uses_component_a'] = 1
counterfactual_data['component_a_inventory'] = model.predict(
    counterfactual_data,
    identified_estimand,
    estimate
)
```

#### 优点
- ✅ 可以量化因果效应
- ✅ 适用于各种干预场景
- ✅ 可以控制混杂变量
- ✅ 有理论保证

#### 缺点
- ❌ 需要正确的因果图
- ❌ 模型假设可能不成立
- ❌ 需要一定的技术能力

---

### 方法2：历史对照法 ⭐⭐⭐⭐

#### 适用场景
- 有明显的时间趋势
- 干预前后对比
- 有足够的历史数据

#### 实施步骤

```python
# 步骤1：分割数据
pre_intervention = data[data['date'] < '2024-11-01']
post_intervention = data[data['date'] >= '2024-11-01']

# 步骤2：建立趋势模型
from sklearn.linear_model import LinearRegression

# 使用干预前数据训练
X = np.arange(len(pre_intervention)).reshape(-1, 1)
y = pre_intervention['inventory'].values
model = LinearRegression()
model.fit(X, y)

# 步骤3：预测反事实（假设趋势延续）
future_X = np.arange(len(pre_intervention), len(data)).reshape(-1, 1)
counterfactual_inventory = model.predict(future_X)

# 步骤4：对比实际与反事实
actual_inventory = post_intervention['inventory'].values
effect = actual_inventory.mean() - counterfactual_inventory.mean()
```

#### 优点
- ✅ 简单直观
- ✅ 不需要复杂的模型
- ✅ 适用于有明显趋势的数据

#### 缺点
- ❌ 假设趋势延续
- ❌ 无法控制其他因素变化
- ❌ 对时间点敏感

---

### 方法3：相似对象对照法 ⭐⭐⭐⭐

#### 适用场景
- 有对照组
- 可以找到相似的对象
- A/B测试场景

#### 实施步骤

```python
# 步骤1：定义匹配变量
matching_vars = ['product_a_sales', 'product_b_sales', 'market_size']

# 步骤2：计算相似度
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import NearestNeighbors

scaler = StandardScaler()
treatment_features = scaler.fit_transform(treatment_group[matching_vars])
control_features = scaler.transform(control_group[matching_vars])

# 步骤3：找到最相似的对照对象
nn = NearestNeighbors(n_neighbors=1)
nn.fit(control_features)
distances, indices = nn.kneighbors(treatment_features)

# 步骤4：构造反事实数据
counterfactual_data = control_group.iloc[indices.flatten()].copy()

# 步骤5：计算因果效应
effect = treatment_group['inventory'].mean() - counterfactual_data['inventory'].mean()
```

#### 优点
- ✅ 可以控制混杂变量
- ✅ 更接近真实情况
- ✅ 适用于有对照组的场景

#### 缺点
- ❌ 需要找到合适的对照组
- ❌ 匹配可能不完全
- ❌ 可能存在未观察的混杂

---

### 方法4：双重差分法（DID）⭐⭐⭐

#### 适用场景
- 面板数据
- 有干预组和对照组
- 有干预前后的数据

#### 实施步骤

```python
# 步骤1：计算干预组的前后差异
treatment_pre = treatment_group[treatment_group['period'] == 'before']['inventory'].mean()
treatment_post = treatment_group[treatment_group['period'] == 'after']['inventory'].mean()
treatment_diff = treatment_post - treatment_pre

# 步骤2：计算对照组的前后差异
control_pre = control_group[control_group['period'] == 'before']['inventory'].mean()
control_post = control_group[control_group['period'] == 'after']['inventory'].mean()
control_diff = control_post - control_pre

# 步骤3：计算双重差分
did_estimate = treatment_diff - control_diff

print(f"因果效应: {did_estimate:.2f}")
```

#### 优点
- ✅ 可以控制时间不变的混杂
- ✅ 可以控制组间差异
- ✅ 适用于面板数据

#### 缺点
- ❌ 需要平行趋势假设
- ❌ 需要对照组
- ❌ 对时间点敏感

---

### 方法5：断点回归设计（RDD）⭐⭐⭐

#### 适用场景
- 有明确的临界点
- 运行变量连续
- 局部因果效应

#### 实施步骤

```python
# 步骤1：定义临界点
cutoff = 100  # 例如：库存水平100

# 步骤2：分割数据
left_data = data[data['running_var'] < cutoff]
right_data = data[data['running_var'] >= cutoff]

# 步骤3：估计临界点两侧的回归
from sklearn.linear_model import LinearRegression

# 左侧回归
left_model = LinearRegression()
left_model.fit(left_data[['running_var']], left_data['inventory'])

# 右侧回归
right_model = LinearRegression()
right_model.fit(right_data[['running_var']], right_data['inventory'])

# 步骤4：计算断点处的跳跃
left_pred = left_model.predict([[cutoff]])[0]
right_pred = right_model.predict([[cutoff]])[0]
treatment_effect = right_pred - left_pred
```

#### 优点
- ✅ 可以看作准实验
- ✅ 不需要对照组
- ✅ 可以估计局部因果效应

#### 缺点
- ❌ 需要明确的临界点
- ❌ 只能估计局部效应
- ❌ 对带宽选择敏感

## 🎯 方法选择指南

### 决策树

```
是否有对照组？
├─ 是 → 是否有干预前后数据？
│   ├─ 是 → 双重差分法（DID）
│   └─ 否 → 相似对象对照法
└─ 否 → 是否有明确的临界点？
    ├─ 是 → 断点回归设计（RDD）
    └─ 否 → 因果模型预测法 或 历史对照法
```

### 推荐优先级

1. **因果模型预测法**（最推荐）
   - 理论基础扎实
   - 适用范围广
   - 可以量化因果效应

2. **相似对象对照法**
   - 实施相对简单
   - 结果可靠
   - 适用于A/B测试

3. **双重差分法**
   - 适用于面板数据
   - 可以控制混杂
   - 需要对照组

4. **历史对照法**
   - 最简单
   - 适用于趋势分析
   - 假设较强

5. **断点回归设计**
   - 适用于特定场景
   - 需要临界点
   - 局部效应

def build_causal_graph():
    """
    步骤1：列出所有相关变量
    步骤2：确定变量之间的因果关系
    步骤3：绘制因果图
    步骤4：验证因果图（专家评审）
    """
    
    causal_graph = """
    digraph {
        # 因果关系
        product_a_sales -> component_a_consumption;
        product_b_sales -> component_a_consumption;

        component_a_consumption -> component_a_inventory;
        
        # 混杂变量

        market_demand -> product_b_sales;

        component_a_procurement -> component_a_inventory;
    }
    """
    
    return causal_graph

## 📊 案例分析

### 案例：产品B是否应该使用部件A？

#### 问题定义
- **现状**：产品B未使用部件A
- **问题**：部件A库存高
- **假设**：如果产品B使用部件A，库存会降低

#### 数据收集
```python
# 收集历史数据
data = pd.DataFrame({
    'date': pd.date_range('2024-01-01', '2024-12-31'),
    'product_a_sales': [...],
    'product_b_sales': [...],
    'product_b_uses_component_a': 0,  # 历史全为0
    'component_a_inventory': [...]
})
```

#### 构造反事实数据
```python
# 使用因果模型预测法
constructor = CounterfactualDataConstructor(data)
counterfactual_data = constructor.method1_causal_model_prediction(
    intervention={'product_b_uses_component_a': 1},
    outcome_variable='component_a_inventory',
    feature_variables=['product_a_sales', 'product_b_sales']
)
```

#### 结果分析
```python
# 对比实际与反事实
actual_mean = data['component_a_inventory'].mean()
counterfactual_mean = counterfactual_data['component_a_inventory'].mean()
reduction = (actual_mean - counterfactual_mean) / actual_mean * 100

print(f"实际库存均值: {actual_mean:.2f}")
print(f"反事实库存均值: {counterfactual_mean:.2f}")
print(f"库存降低: {reduction:.2f}%")
```

#### 结论
- 如果库存降低超过20%，则产品B未使用部件A是核心根因
- 建议修改产品B的BOM配置，让产品B也使用部件A

## 💭 总结

在实际场景中构造反事实数据：

1. **首选因果模型预测法**
   - 理论基础扎实
   - 适用范围广
   - 可以量化因果效应

2. **根据数据情况选择方法**
   - 有对照组 → 相似对象对照法或DID
   - 有临界点 → RDD
   - 有趋势 → 历史对照法

3. **验证结果的稳健性**
   - 敏感性分析
   - 多种方法对比
   - 专家评审

4. **结合业务知识**
   - 因果图需要业务理解
   - 结果解释需要业务背景
   - 建议需要可行性分析

**记住**：反事实分析是因果推断的核心，它帮助我们回答"如果...会怎样？"的问题，为决策提供科学依据！🎯
