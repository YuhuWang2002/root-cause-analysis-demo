# 实际场景中构造反事实数据 - 快速指南

## 🎯 核心问题

**我们只能观察到一种情况（实际发生了什么），但想知道另一种情况（如果...会怎样？）**

## 💡 五种实用方法

### 1. 因果模型预测法 ⭐⭐⭐⭐⭐（最推荐）

**原理**：基于历史数据训练因果模型，预测干预后的结果

**适用场景**：
- ✅ 有历史数据
- ✅ 可以建立因果模型
- ✅ 需要量化干预效果

**实施步骤**：
```python
# 1. 收集历史数据
historical_data = pd.read_csv('inventory_history.csv')

# 2. 建立因果模型（使用DoWhy）
from dowhy import CausalModel

model = CausalModel(
    data=historical_data,
    treatment='product_b_uses_component_a',
    outcome='component_a_inventory',
    graph=causal_graph
)

# 3. 识别和估计因果效应
identified_estimand = model.identify_effect()
estimate = model.estimate_effect(identified_estimand)

# 4. 预测反事实结果
counterfactual_data = historical_data.copy()
counterfactual_data['product_b_uses_component_a'] = 1
counterfactual_data['component_a_inventory'] = model.predict(counterfactual_data)
```

**优点**：理论基础扎实，适用范围广，可以量化因果效应
**缺点**：需要正确的因果图，模型假设可能不成立

---

**原理**：使用干预前的数据作为基线，假设趋势延续

**适用场景**：
- ✅ 有明显的时间趋势
- ✅ 干预前后对比
- ✅ 有足够的历史数据

```python

post_data = data[data['date'] >= intervention_date]

# 2. 建立趋势模型

```

**优点**：简单直观，不需要复杂的模型
**缺点**：假设趋势延续，无法控制其他因素变化

---

### 3. 相似对象对照法 ⭐⭐⭐⭐

**原理**：找到与干预组相似但未受干预的对象，使用对照组的结果作为反事实

**适用场景**：
- ✅ 有对照组
- ✅ 可以找到相似的对象
- ✅ A/B测试场景

**实施步骤**：
```python

# 4. 计算因果效应
```

**优点**：可以控制混杂变量，更接近真实情况
**缺点**：需要找到合适的对照组，匹配可能不完全

---

### 4. 双重差分法（DID）⭐⭐⭐

**原理**：比较干预组和对照组在干预前后的变化差异

**适用场景**：
- ✅ 面板数据
- ✅ 有干预组和对照组
- ✅ 有干预前后的数据

**实施步骤**：
```python
# 1. 计算干预组的前后差异
treatment_diff = treatment_post - treatment_pre

# 2. 计算对照组的前后差异
control_diff = control_post - control_pre

# 3. 计算双重差分
did_estimate = treatment_diff - control_diff
```

**优点**：可以控制时间不变的混杂，可以控制组间差异
**缺点**：需要平行趋势假设，需要对照组

---

### 5. 断点回归设计（RDD）⭐⭐⭐

**原理**：利用某个连续变量的临界点，比较临界点两侧的结果

**适用场景**：
- ✅ 有明确的临界点
- ✅ 运行变量连续
- ✅ 局部因果效应

**实施步骤**：
```python

# 2. 分割数据

```

**优点**：可以看作准实验，不需要对照组
**缺点**：需要明确的临界点，只能估计局部效应

## 🎯 方法选择决策树

```
是否有对照组？
├─ 是 → 是否有干预前后数据？
│   ├─ 是 → 双重差分法（DID）
│   └─ 否 → 相似对象对照法
└─ 否 → 是否有明确的临界点？
    ├─ 是 → 断点回归设计（RDD）
    └─ 否 → 因果模型预测法 或 历史对照法
```

## 📊 实际案例：部件A库存问题

### 问题
- 产品B未使用部件A
- 部件A库存高
- 想知道：如果产品B使用部件A，库存会降低多少？

### 解决方案（使用因果模型预测法）

```python
# 1. 收集历史数据
data = pd.read_csv('inventory_actual_data.csv')

# 2. 建立因果模型
from causal_analyzer import InventoryCausalAnalyzer

analyzer = InventoryCausalAnalyzer(data)

# 3. 构造反事实数据
counterfactual_data = analyzer.generate_counterfactual_data(
    intervention={'product_b_uses_component_a': 1}
)

# 4. 对比分析
actual_mean = data['component_a_inventory'].mean()  # 153.73
counterfactual_mean = counterfactual_data['component_a_inventory'].mean()  # 2.17
reduction = (actual_mean - counterfactual_mean) / actual_mean * 100  # 98.59%

# 5. 结论
if reduction > 20:
    print("✅ 产品B未使用部件A是核心根因")
    print(f"如果产品B使用部件A，库存可降低{reduction:.2f}%")
```

## 💡 关键要点

### 1. 数据质量要求
- ✅ 样本量足够（建议>100）
- ✅ 无缺失值或已处理
- ✅ 时间连续
- ✅ 变量定义清晰

### 2. 因果图构建
- ✅ 基于业务知识
- ✅ 包含所有相关变量
- ✅ 明确因果关系方向
- ✅ 专家评审验证

### 3. 结果验证
- ✅ 敏感性分析
- ✅ 多种方法对比
- ✅ 业务合理性检查
- ✅ 稳健性检验

### 4. 实施建议
1. **首选因果模型预测法**（理论最扎实）
2. **根据数据情况调整**（有对照组用相似对象对照法）
3. **多种方法交叉验证**（提高结果可信度）
4. **结合业务知识解释**（确保结果合理）
