# 部件A库存高因果根因分析系统

## 项目简介

本系统使用DoWhy因果推断框架，分析部件A库存高的根本原因。通过因果建模、识别、估计、驳斥检验和反事实分析，验证**产品B未使用部件A**是否为部件A库存高的核心因果根因。

## 核心功能

### 1. 数据生成
- 生成产品A、产品B销量数据
- 生成部件A库存、消耗、采购数据
- 支持反事实数据生成（产品B使用部件A）

### 2. 因果分析
- **因果建模**：构建因果图，明确变量关系
- **因果识别**：使用后门调整识别因果效应
- **因果估计**：计算平均处理效应（ATE）
- **驳斥检验**：安慰剂检验、随机共同原因检验、数据子集检验
- **反事实分析**：比较实际库存与反事实库存

### 3. 可视化展示
- 因果图可视化
- 库存趋势对比图
- 销量趋势图
- 指标对比分析

### 4. 大模型解释
- 生成业务化的根因分析报告
- 包含根因分析、影响机制、量化影响、改进建议

## 技术栈

- **Python 3.8+**
- **DoWhy**: 因果推断框架
- **Streamlit**: Web应用框架
- **Plotly**: 交互式可视化
- **NetworkX**: 因果图构建
- **OpenAI API**: 大模型接口

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置大模型API（可选）

创建 `modelkey.cfg` 文件：

```
API Key: your_api_key_here
Base URL: https://api.siliconflow.cn/v1
Model: Qwen/Qwen2.5-7B-Instruct
```

### 3. 启动应用

**Linux/Mac:**
```bash
chmod +x run_demo.sh
./run_demo.sh
```

**Windows:**
```bash
run_demo.bat
```

或者直接运行：
```bash
streamlit run app.py
```

### 4. 访问应用

在浏览器中打开：http://localhost:8501

## 使用指南

### 页面导航

1. **场景介绍**：了解分析背景和目标
2. **因果图**：查看变量之间的因果关系
3. **数据探索**：分析库存和销量趋势
4. **因果分析**：运行DoWhy因果分析，查看结果
5. **大模型解释**：生成业务化的根因分析报告

### 分析流程

1. 在"场景介绍"页面点击"开始分析"生成数据
2. 在"因果图"页面了解变量关系
3. 在"数据探索"页面查看数据趋势
4. 在"因果分析"页面运行因果分析
5. 在"大模型解释"页面生成智能报告

## 验收标准

### 分析结果验收
- ✅ 因果图清晰，变量关系符合业务逻辑
- ✅ ATE为负且绝对值合理，证明"用A→降库存"
- ✅ 反事实库存显著低于实际库存
- ✅ 安慰剂效应接近0，稳健检验通过
- ✅ 明确判定：产品B未使用部件A是根因

### Web页面验收
- ✅ 可正常打开、加载稳定
- ✅ 展示：核心指标卡片、趋势对比图、因果图
- ✅ 页面简洁、数据可读、支持汇报

### 大模型解释验收
- ✅ 无专业术语，业务人员可看懂
- ✅ 包含：表面原因、核心根因、量化影响、优化建议
- ✅ 逻辑通顺、结论与分析一致

## 扩展功能

## 注意事项

1. 确保Python版本 >= 3.8
2. 需要安装graphviz系统依赖（用于因果图可视化）
3. 大模型功能需要配置API密钥
4. 首次运行会生成模拟数据，可能需要几秒钟
