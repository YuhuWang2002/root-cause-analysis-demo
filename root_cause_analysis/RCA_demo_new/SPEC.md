# 根因分析系统设计规范

## 1. 项目概述

### 1.1 项目名称与类型
本项目为一个**根因分析（Root Cause Analysis）Web应用系统**，旨在演示从数据采集到因果分析的完整流程。

### 1.2 核心功能概述
系统提供三个主要功能模块：项目列表管理、创建项目配置向导、以及分析流程可视化展示。用户可通过直观的界面完成从数据源配置到根因识别的全流程分析任务。

### 1.3 目标用户
数据分析工程师、系统运维人员、质量管理人员，以及需要进行问题根因分析的企业用户。

## 2. UI/UX 规范

### 2.1 布局结构

#### 页面架构
系统采用**单页应用（SPA）**架构，包含三个主要视图：

1. **项目列表视图**（Home）：展示所有已创建的分析项目
2. **创建项目视图**（Create）：分步骤配置分析项目
3. **分析流程视图**（Flow）：展示完整的分析流程图

#### 布局规格
- **顶部导航栏**：高度64px，固定定位，包含系统Logo、项目切换器
- **侧边栏**：宽度280px，可折叠，收起时宽度为64px
- **主内容区域**：自适应宽度，最小宽度800px
- **底部状态栏**：高度32px，显示系统状态信息

#### 响应式断点
- 桌面端：≥1200px（完整布局）
- 平板端：768px - 1199px（侧边栏收起）
- 移动端：<768px（侧边栏隐藏，底部导航）

## 3. 功能规范

### 3.1 项目列表页面

#### 页面组成
1. **页面标题区域**
   - 标题：「我的项目」或「项目列表」
   - 副标题：项目总数统计
   - 新建项目按钮（右上角）

2. **搜索过滤栏**
   - 搜索输入框：支持按项目名称搜索
   - 状态筛选下拉框：全部/进行中/已完成
   - 时间排序：最新创建/最早创建

3. **项目卡片网格**
   - 响应式网格布局：桌面3列，平板2列，移动端1列
   - 每个卡片包含：项目名称、描述、创建时间、状态标签、进度条、操作按钮

4. **空状态**
   - 当无项目时显示：插画 + 「创建您的第一个项目」引导文案

#### 交互行为
- 点击卡片进入项目详情/分析流程
- 点击「新建项目」进入创建向导
- 支持批量操作（选择多个项目进行删除/导出）
- 右键菜单：编辑、复制、删除、导出

### 3.2 创建项目页面

创建项目页面采用**分步向导**形式，共7个步骤：

#### 步骤1：基本信息（对应设计文档步骤1）
- 项目名称：必填，最长50字符
- 项目描述：选填，最长500字符，支持富文本
- 分析场景选择：下拉选择（系统异常分析、性能问题分析、质量问题分析、自定义场景）

#### 步骤2：数据源配置（对应设计文档步骤2）
- 数据源类型：MySQL、PostgreSQL、MongoDB、API、CSV文件
- 连接配置：主机、端口、数据库名、用户名、密码（加密存储）
- 连接测试按钮：验证连接是否成功
- 支持添加多个数据源

#### 步骤3：数据权限配置（对应设计文档步骤3）
- 表选择：树形结构展示可访问的表，支持多选
- 字段选择：选择每个表中需要读取的字段
- 数据范围：时间范围筛选、行数限制
- 权限预览：显示已配置的数据权限摘要

#### 步骤4：数据转换配置（对应设计文档步骤4）
- 输出格式：JSON、Parquet、Delta Lake
- 存储位置：本地路径或数据湖地址
- 转换规则：字段映射、数据类型转换、计算字段
- 调度配置：立即执行/定时执行/手动触发

#### 步骤5：数据质量约束（对应设计文档步骤5）
- 约束类型：非空检查、唯一性检查、范围检查、格式检查、自定义SQL
- 告警阈值：告警级别（info/warning/error）、触发条件
- 质量报告：是否生成数据质量报告
- 质量规则可视化：规则之间的关系图

#### 步骤6：本体构建（对应设计文档步骤6.1）
- 本体类型：事件本体、因果本体、层次本体
- 实体定义：添加实体类型、属性、关系
- 关系定义：定义实体间的关系类型（因果、包含、依赖等）
- 本体预览：可视化的本体图

#### 步骤7：分析配置（对应设计文档步骤6.2-6.3）
- 分析方法：因果分析、根因识别、关联分析
- 算法选择：PC算法、FCI算法、GRaSP算法等
- 参数配置：置信度阈值、最大因果路径长度等
- 输出配置：分析结果展示格式、导出格式

#### 向导交互
- 步骤导航：顶部步骤指示器 + 侧边目录
- 上一步/下一步按钮
- 保存草稿功能
- 步骤验证：每个步骤完成后进行必填项验证
- 整体提交：所有步骤完成后点击「创建项目」

### 3.3 分析流程页面

#### 页面组成
1. **流程图展示区**（核心区域）
   - 横向流程布局，从左到右
   - 包含数据采集、数据处理、本体构建、数据分析四个阶段
   - 每个阶段包含多个可展开的子节点

2. **节点详情面板**
   - 右侧滑出面板
   - 显示选中节点的详细信息
   - 支持节点操作：重新运行、查看日志、修改配置

3. **流程控制栏**
   - 播放/暂停按钮：控制流程自动演示
   - 步骤按钮：上一步/下一步
   - 速度控制：慢速/正常/快速
   - 全屏按钮

4. **状态面板**
   - 当前执行节点高亮
   - 执行进度百分比
   - 耗时统计
   - 错误/警告信息

#### 流程节点详情
每个节点包含以下信息：
- 节点名称与图标
- 状态：等待中/执行中/已完成/失败
- 执行时间
- 输入输出数据摘要
- 详细日志入口

#### 可视化效果
- 节点使用不同的颜色区分类型
- 连接线使用动画虚线表示数据流动
- 当前执行节点有脉冲动画
- 完成节点有勾选标记动画
- 失败节点有闪烁警示效果

## 4. 技术架构

### 4.1 技术栈
- **前端框架**：React 18 + TypeScript
- **状态管理**：Zustand
- **路由**：React Router v6
- **流程图**：React Flow
- **样式方案**：Tailwind CSS + CSS Modules
- **动画**：Framer Motion
- **图表**：Recharts
- **构建工具**：Vite

### 4.2 项目结构
```
src/
├── components/          # 可复用组件
│   ├── common/          # 通用组件（按钮、输入框、卡片等）
│   ├── layout/          # 布局组件
│   ├── flow/            # 流程图相关组件
│   └── wizard/          # 向导组件
├── pages/               # 页面组件
│   ├── ProjectList/     # 项目列表页
│   ├── CreateProject/   # 创建项目页
│   └── AnalysisFlow/    # 分析流程页
├── stores/              # 状态管理
├── hooks/               # 自定义Hooks
├── utils/               # 工具函数
├── types/               # TypeScript类型定义
├── styles/              # 全局样式
└── App.tsx              # 应用入口
```
