# 根因分析系统重构实施计划

## 重构目标
将现有的泳道式流程图改为拖拽式的流程图编辑器，保持阶段分区概念，更灵活、更直观，类似 drawio。

## 阶段分区设计（subgraph）
画布分为4个垂直区域（从左到右），每个区域使用 subgraph 概念，不固定宽度：
1. **数据源区** - 只允许放置数据源节点
2. **数据 Pipeline 区** - 只允许放置数据表、数据处理节点
3. **数据集区** - 只允许放置数据集节点
4. **数据分析区** - 只允许放置本体构建、数据分析、根因分析节点

## 重构内容

### 1. 左侧工具栏（节点类型）
- 添加可拖拽的节点图标面板
- 包含以下节点类型：
  - 数据源（Source）
  - 数据表（Data Table）
  - 数据处理（Process）
  - 数据集（Dataset）
  - 本体构建（Ontology）
  - 数据分析（Analysis）
  - 根因分析（Root Cause）

### 2. 右侧画布（类似 drawio）
- 画布支持缩放（放大/缩小/适应画布）
- 画布支持拖拽平移
- 画布分为4个垂直区域（subgraph）
- subgraph 使用 flex 布局，自适应内容宽度
- 节点可在区域内自由拖动
- 节点之间可连线

### 3. 右侧配置面板
- 点击节点时从右侧弹出配置面板

## 实施步骤

### 步骤 1：创建左侧工具栏组件 (ToolPalette)
- 创建 ToolPalette.tsx
- 包含可拖拽的节点图标（7种类型）
- 实现拖拽开始的事件
- 节点只能在对应区域放置

### 步骤 2：修改 FlowCanvas 支持缩放和平移
- 添加缩放控制按钮（+/=/-）
- 使用 transform: scale() 实现缩放
- 支持鼠标拖拽平移画布
- 画布背景网格

### 步骤 3：修改 FlowCanvas 为带分区的画布（subgraph）
- 创建4个垂直区域（flex 布局）
- 使用 subgraph 样式（非固定宽度）
- 区域标题显示
- 区域只能接受对应类型节点

### 步骤 4：实现节点拖拽移动
- 支持从工具栏拖拽到画布
- 支持在画布上拖拽移动节点
- 更新节点位置到 store

### 步骤 5：实现节点连线功能
- 添加连接点（Handle）
- 实现连线绘制（SVG）
- 支持从节点拖出连线

### 步骤 6：修改配置面板位置
- 从左侧弹出改为右侧弹出

### 步骤 7：更新样式和交互
- 优化节点样式
- 添加拖拽反馈
- 连线样式优化
