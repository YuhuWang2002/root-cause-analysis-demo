# 本体构建功能实施计划

## 阶段目标
实现本体构建阶段的配置功能，包括本体模板选择、实体映射配置、关系定义等。

## 本体构建功能分析

根据设计文档，本体构建是将数据资产转换为结构化本体（Ontology）的过程，用于后续的本体探索和数据分析。

核心功能：
1. **本体模板选择** - 根据分析场景选择预定义的本体模板
2. **实体映射** - 将数据表字段映射到本体实体
3. **关系定义** - 定义实体之间的关系
4. **属性配置** - 配置实体的属性

## 实施步骤

### 步骤 1：在 ConfigPanel 中添加 OntologyConfig 组件
- 创建 OntologyConfig 组件
- 本体模板选择（系统异常、质量问题、性能问题、自定义）
- 实体映射配置（选择数据表字段，映射到实体）
- 关系定义（定义实体之间的关系，如因果、依赖、组成等）

### 步骤 2：更新 renderConfigContent 开关语句
- 添加 'ontology' case 处理

### 步骤 3：测试验证
- 验证本体构建配置面板正常显示
- 验证配置可以保存
